# Todo Fullstack App

Fullstack додаток для керування списком задач, побудований на React (фронтенд) та Express.js (бекенд).

## Функціонал
* Отримання списку задач із сервера
* Додавання нових задач
* Видалення задач
* Редагування тексту та статусу задач

## Структура проєкту
* /server — бекенд на Express.js
* /src — фронтенд на React (Vite)
